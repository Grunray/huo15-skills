Vibe Web

Powered by Three.js + GSAP + Lenis

Features

3D Rendering

WebGL2 powered real-time 3D with Draco compressed GLB models, bloom post-processing, and particle systems.

Scroll Animations

GSAP ScrollTrigger drives pinning, scrubbing, and timeline chains for immersive scroll storytelling.

Smooth Scrolling

Lenis provides buttery smooth inertia scrolling, synced with GSAP ticker for perfect animation alignment.
