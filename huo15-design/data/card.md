# 卡片 / 名片 / 印刷品 A4 拼版

> HTML 写卡 → A4 一页排多张 → PDF → 打印裁切。双面对齐、剪刀友好、印刷可读。

## 工作流

```bash
# 1) 编辑 scripts/make_card.py 顶部 CONFIG：卡片尺寸、行列数、正反文案、二维码图
python3 scripts/make_card.py                       # → card_sheet.html（二维码 base64 内嵌，自包含）
# 2) 渲染（双面 2 页 + 分页正/反单页）
node scripts/render_pdf.js card_sheet.html 龙虾卡片.pdf
```
`make_card.py` 用 CSS `@page size:A4 landscape; margin:0`、mm 单位精确出血到位。

## 名片标准尺寸

- 中国标准名片 **90×54mm**（5:3，推荐）；信用卡 85.6×54；U盘卡可 90×54 或更小。
- A4 横向（297×210）放 90×54：**3 列 × 3 行 = 9 张/页**，零间隙时栅格 270×162mm 居中。

## 双面对齐（关键，一定要对得上）

- **居中 + 对称栅格**（列数/行数左右上下对称）+ **同面每张内容完全相同** ⇒ 双面打印翻面后背面必落在正面背后，**无需镜像反面**，长边/短边翻页都行。
- 自检：印完灯光下透看，正反裁切细线网格应**完全重合**。
- 打印设置铁律：**实际大小 / 100% / 不缩放**（选「适合页面」会缩约 96%，尺寸+对位全废）；A4 横向；≥250g 卡纸。
- 容差：家用打印机双面套准常 ±1-2mm；卡内留白 5-7mm，偏移肉眼无感，看正面那面的线剪。

## 裁切线（剪刀友好）

- 卡片 `outline:0.2mm solid #d2cfc8`（极细极浅灰）；**零间隙**相邻卡共用一条线，剪刀沿线一刀分两张、无废边。
- `outline-offset:-0.1mm` 让线压在卡边、相邻共线不重影。
- 备选：四角 crop marks（落在间隙里），适合留间隙的版式。

## 印刷可读性（老人友好硬规则）

打印「看不清」的根因 = 浅灰字 + 过小字号在纸上发虚。修法：
- 可读文本印刷色**不浅于 `#666`**；中文正文近黑 `#1a1a1a`。
- 字号**≥ ~6.5px**；小字 `font-weight:500`（细笔画印刷不丢）。
- 屏幕好看 ≠ 打印清晰，务必按上面下限。

## 版式经验（主题为主角）

- 品牌缩成**角落小标识**（logo 7-9mm + 名称小字），**主题大字 + 寄语**占大版面（hero ~27-30px）。
- 寄语去掉破折号更利落；中英寄语可上下排，英文极小号（`#6a6a6a` 7-8.5px）。
- 二维码：**能扫即可**，10-13mm，放角落；不喧宾夺主。
- 版权/署名可放底部小字或按需移除。

## 分页交付

- `render_pdf.js` 用 puppeteer `pageRanges` 同时导出：**双面合并版**（自动双面打印）+ **正面单页 / 反面单页**（不支持自动双面时，先印正面、翻面重喂、再印反面）。
